The two zones of modux: the code that is yours, and the code that is generated. The library from episode 2 gets a custom operation, withdraw, whose intent is written in the model in plain words. Generation declares a hook and scaffolds a default implementation in a module of your own; you write the rule there, or let mvn modux:ai-complete draft it from the intent with the AI command line on your machine. Then the model changes, generation runs again, and your module is untouched; a generated file edited by hand is reported and put back. Finally, the rule running in the deployed system.

Everything on screen is real: the commands' actual output, the files as modux 0.6.7 writes them, and the generated system running in Docker.
